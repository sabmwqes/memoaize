# memoaize 🗿

単語帳を作って、自分のペースで覚えるブラウザアプリ。

公開先: https://sabmwqes.github.io/memoaize/ （今回の変更はデプロイ前）

## 開発

Node.js 24 以降を使用します。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

## 使い方

1. 単語帳のタイトルと色を選び、カードを追加するか TSV を取り込みます。
2. `START STUDY` から、対象・方向・シャッフル・手動／自動を選びます。
3. 手動学習の `AGAIN` で苦手に登録し、残り枚数に応じた間隔で再出題します。`NEXT` では苦手を解除しません。
4. コンピレーションを作ると、複数の単語帳をまとめて学習できます。元の更新と苦手の記録を共有します。

データは使用しているブラウザに保存します。ブラウザのデータ削除に備え、または別端末に移すときは、バックアップを保存してください。復元は現在の全データを置き換えます。

TSV はヘッダーなしの「単語・意味」の2列です。単語帳ごとの情報や苦手の登録まで保存するには JSON バックアップを使います。
