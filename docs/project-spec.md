# memoaize 初版の仕様と実装状況

この文書は、会話で合意した仕様と、実装を動かすために置いた暫定的な選択を分けて記録する。
「実装済み」は、その細部まで利用者が承認したという意味ではない。
当初の構想は [project-brainstorm.md](./project-brainstorm.md) に残す。

## 1. 会話で確認済みの方針

- 基本的には自分用の暗記学習アプリ。React を使い、GitHub Pages で公開する。🗿 がトレードマーク。
- 分野ごとに単語帳を作り、コンピレーションでまとめる。元の単語帳の更新を反映し、独立したコピーにしない。
- 基本は毎回すべてを学習する。「苦手だけ」も選べる。シャッフルは初期値 ON のトグル。
- 手動学習では答えや一文字のヒントを表示できる。
- 「もう一度」は、そのセッション内で再出題する。残りカードが多いほど、再出題までの間隔を長くする。
- 苦手の登録は、思い出せただけでは解除せず、明示的に解除するまで残す。
- 自動学習は食事中などに眺める用途。OK／もう一度の操作を要求しない。
- 保存は使用しているブラウザ内。ファイルでバックアップ・別端末への移行を行う。
- 苦手はカードごとに1つ。出題方向を変えても、通常の単語帳とコンピレーションを切り替えても共有する。

## 2. 実装済みの機能

| 分類 | 動作 |
| --- | --- |
| 単語帳 | タイトル・プリセット色・カスタムカラーを指定して作成、編集、削除 |
| カード | 単語／問題と意味／答えを入力して追加、編集、削除。複数行に対応 |
| コンピレーション | 通常の単語帳を選んでまとめる。元の追加・編集・削除が反映される |
| 管理 | お気に入り、単語帳名の検索、カード内容の検索、苦手カードがある単語帳の表示 |
| 手動学習 | 全部／苦手だけ、両方向の出題、シャッフル、答え表示、一文字ヒント、再出題、苦手解除 |
| 自動学習 | 問題と答えを指定時間表示して次へ進む。一時停止・再開 |
| TSV | ファイル／貼り付けからの追加、プレビュー、不正な行の検出、単体・全カードの出力 |
| 保存 | 編集・苦手の変更・学習設定をブラウザ内に保存。保存失敗は通知し、操作を確定しない |
| バックアップ | JSON に全データを書き出し、検証と確認後に復元 |
| 表示 | PC・スマートフォン向けの画面、日本語表示、🗿 のアイコン |

## 3. 再出題間隔

残りカード数に応じて伸ばす方針を採用している。係数の例として提案された `0.5` を使う。
下限・端数処理・残りが少ない場合の扱いは、次の**暫定的な実装値**とする。

```text
N = 今答えたカードを除く、待機中のカード枚数
間に挟む枚数 = min(N, max(3, ceil(N × 0.5)))
```

| 待機中 N | 間に挟む枚数 | 挙動 |
| --- | --- | --- |
| 0 | 0 | 同じカードを答えを隠して再出題 |
| 1〜2 | N | 待機中の最後に追加 |
| 4 | 3 | 3枚を出題した後に再出題 |
| 7 | 4 | 4枚を出題した後に再出題 |
| 20 | 10 | 10枚を出題した後に再出題 |
| 100 | 50 | 50枚を出題した後に再出題 |

「もう一度」を選ぶたびに、その時点の N で計算する。再出題待ちのカードも N に含む。
初期キューは元のカードごとに1枚とし、回答したカードを取り除いてから再挿入するため、
同じカードの再出題待ちが二重には増えない。

## 4. 手動学習と苦手

| 操作 | 動作 |
| --- | --- |
| 答えを見る | 答え全体を表示 |
| 一文字だけ見る | 答えを一文字ずつ表示 |
| NEXT（次へ） | 苦手の登録を変更せず次へ |
| AGAIN（もう一度） | 苦手に登録し、キューに再挿入 |
| CLEAR & NEXT（苦手から外して次へ） | 苦手を解除し、次へ |

「次へ」は以前の「OK」に対応する。苦手の解除を別操作にする提案への賛同を受けて実装した。
ラベルやボタン配置は、個別に確認が完了した最終デザインとしては扱わない。

苦手解除のボタンは、答えを表示した後、苦手に登録されているカードだけに表示する。
カード一覧からも解除できる。自動学習では記録を変更しない。

### 手動学習の暫定的な選択

- ヒントは左から表示し、空白・改行だけのために追加の操作を要求しない。結合文字・絵文字は途中で分割しない。
- ヒントを使っただけでは苦手に登録しない。全部見えたら答え表示後と同じ操作を出す。
- カードの編集後も苦手を維持する。カードの削除時は苦手の記録も削除する。
- キューが空になればセッション終了。苦手に残っているだけでは再出題しない。
- 途中終了・再読み込みではセッションを再開しない。すでに保存した苦手の変更は残る。
- 対象と出題内容は開始時に確定する。日付による出題内容の変更は行わない。

## 5. 自動学習の暫定的な選択

- 問題を表示 → 答えを表示 → 次のカード、の順に進める。
- 初期値は問題5秒・答え3秒。それぞれ1〜60秒の整数で変更できる。
- 一時停止時は残り時間を維持し、再開後に続ける。
- 全カードを1巡したら終了する。初版には繰り返しの設定を設けていない。
- タブ切り替えなどで画面が非表示になると停止し、戻った後に利用者が再開する。

## 6. 保存とファイル形式の暫定的な選択

### ブラウザ保存

- `localStorage` の `memoaize.library.v1` に保存する。
- 保存するのは単語帳・カード・コンピレーションの参照・色・お気に入り・苦手の登録・学習設定。
- 「全部／苦手だけ」は保存せず、学習開始画面では毎回「全部」に戻す。
- 学習中の出題キューは保存しない。
- ブラウザや端末が違う場合は別の保存領域になる。自動同期は行わない。
- 読み込めない保存内容を自動的に空データで上書きしない。元の内容の退避、バックアップの復元、確認後の初期化を用意する。

### TSV

- UTF-8、ヘッダーなし、単語と意味の2列。両方必須。
- セル内のタブ・改行・引用符には CSV と同じ引用規則を使う。
- BOM、LF／CRLF、単一の Markdown コードブロックに囲まれた貼り付けに対応する。
- プレビューしてから追加。不正な行があれば全体を取り込まず、位置と理由を表示する。
- 既存カードの上書きや文面による重複排除は行わない。
- 単体出力は、選んだ単語帳またはコンピレーションのカード内容を出す。
- 一括出力は、通常の単語帳の全カードを1つの TSV にまとめる。単語帳の区切りや苦手の記録は含めない。

### バックアップ

- JSON に単語帳の区切り、コンピレーション、苦手、設定を含む全データを保存する。
- 復元前に形式、バージョン、ID の重複、参照関係、設定値を検証する。
- 復元は全置き換え。内容の件数と置き換えることを表示し、確認後に保存する。
- 不正なファイルや保存失敗では、現在のデータを置き換えない。

## 7. 管理画面の暫定的な選択

- コンピレーションには通常の単語帳だけを含める。入れ子にはしない。
- 元の単語帳の削除前に、参照しているコンピレーションの件数を表示する。
- 削除後は参照から外し、コンピレーション自体は残す。
- コンピレーションからカードを編集するときは、元の単語帳へ移動する。
- シャッフル OFF では、カードの追加順。コンピレーションでは単語帳を選択した順にまとめる。
- お気に入りを一覧の先頭に表示する。
- カードがない場合は学習開始ボタンを無効にする。苦手だけの対象が空なら「全部」への切り替えを案内する。

## 8. 確認と今後の調整

- デザインは [design.md](./design.md) を参照。黒基調・角丸なし・虹色のアクセント・英語を主とする表示は利用者の指定。具体的な色や配置の選択は別に記録する。

- 自動テスト: 可変間隔の再出題、苦手の共有、参照更新、バックアップ検証、TSV の往復と不正入力、保存失敗と壊れた保存内容の保護。
- ブラウザ確認: 作成・編集・削除、TSV、手動学習、ヒント、実際の出題順、再読み込み、逆方向での苦手解除、自動学習と停止・再開、バックアップ復元、スマートフォン幅。
- 未確認の細部は、上記の「暫定的な選択」として試用後に調整する。新たな合意が得られたら、その項目だけ確認済みへ移す。
- 今回はアプリの実装とローカル確認まで。GitHub Pages への反映はデプロイ後。
