# memoaize デザインメモ（新案）

PR #1（Codex 版）と比較するために作り直した案の考え方。
仕様の土台は [project-brainstorm.md](./project-brainstorm.md)。データ形式は PR #1 と互換で、JSON バックアップを相互に復元できる。

## 前提にしたこと

- **主な端末はスマホ。** 自分用・食事中に眺める自動送りなど、片手で使う場面が中心。PC は 2 カラムで広く使う。
- **毎回の操作を短くする。** 開いてから学習開始まで 1〜2 タップ。設定はモーダルに隠さず、単語帳画面にその場で切り替えられる形で置く（前回の設定を記憶）。
- **画面の飾りを減らす。** 「WORKSPACE / 01」「LOCAL FIRST」のような装飾ラベルや、保存のたびに出る通知はやめ、カードと操作に面積を使う。

## 見た目

- 黒基調・角丸なし・高コントラスト・虹色の差し色（利用者の指定）はそのまま。
- 虹の 7 色は役割で使い分ける。

  | 色 | 役割 |
  | --- | --- |
  | 赤 | 削除・エラー |
  | 橙 | 苦手（WEAK）・AGAIN |
  | 黄 | お気に入り・ヒント |
  | 緑 | 主操作・答え |
  | 水色 | 選択・フォーカス・移動 |
  | 紫 | コンピレーション・取り込み |

- 画面上端の虹帯はブランドの印。学習中の進み具合は白い細線（虹帯と役割を分ける）。

## 動き（ミニマルに、立体感を少し）

- **左から染まる**: ボタンを押す・乗せる、選択肢を選ぶ、答えを表示する、WEAK を付ける、といった操作で、背景色が `clip-path` で左から右へ染まる。動きの方向は一方向にそろえる。
- **押し込み**: 主操作（緑）のボタンは影のない固い段差を持ち、押すと沈む。
- **カードの束**: 学習中のカードの後ろに、残りのカードを最大 2 枚分の束として重ねる。次のカードは束から持ち上がるように出る。
- **背景**: 点のグリッドが上から薄れながら、ゆっくり流れる。黒一色の画面に奥行きを足すためのもの。
- PC では、単語帳の行に乗せると少し浮いて、単語帳の色の影が出る。
- `prefers-reduced-motion` のときは止める。
- 文字: UI・カードは IBM Plex Mono、見出しと単語帳名は Rajdhani、ロゴは Orbitron。日本語は端末のフォント。
- 最小の文字サイズは 10〜11px（ラベル）。本文は 13〜16px、カードの問題は最大 46px。
- アイコンは SVG で統一（絵文字は 🗿 だけ）。端末ごとに見た目が変わらないようにする。

## 画面

| 画面 | 要点 |
| --- | --- |
| 一覧 | 概要は 1 行。苦手があれば「REVIEW WEAK」で全単語帳の苦手をまとめて復習。各行に ★ と ▶（前回の設定ですぐ学習）。新規作成は親指の届く下部に固定 |
| 単語帳 | タイトル → STUDY パネル（QUIZ: 出題の向き。押すと入れ替わり、1 枚目で「remember → ?」のように見せる／範囲・順番・モード）→ START。カードは一覧で、タップで編集、⚑ で苦手を切り替え。追加は連続入力できるフォーム |
| 取り込み | ① AI 向けプロンプトをコピー → ② 返ってきた TSV を貼り付け → プレビューして追加 |
| 学習 | カード全体をタップで答え表示。下に HINT / REVEAL、表示後は AGAIN / OK。苦手の解除はカード右上の WEAK を押す（明示的な操作） |
| 自動送り | 問題 → 答え → 次へ。残り時間を細い帯で表示、タップで一時停止。LOOP で繰り返し。再生中は画面を消さない（対応ブラウザ） |
| データ（一覧の「…」） | BACKUP / RESTORE / EXPORT ALL TSV / サンプル追加 / RESET。RESET は、その場でバックアップを保存でき、「本当に消去する」にチェックするまで押せない |
| 完了 | 🗿 CARVED. 回数・AGAIN 数・苦手の数。「WEAK だけもう一度」「もう一周」 |

## 用語

| 画面の表記 | 意味 |
| --- | --- |
| WEAK / ⚑ | 苦手。カードごとに 1 つ。単語帳とコンピレーション、出題方向で共有 |
| AGAIN | 苦手に登録し、少しあとにもう一度出題（残り枚数 × 0.5、最低 3 枚あと） |
| OK | 次へ。苦手の登録は変えない |
| COMPILATION | 複数の単語帳をまとめたもの。元の単語帳を参照する |

## PR #1 から変えた主な点

- 学習開始のモーダルをやめ、単語帳画面の STUDY パネルに統合。一覧からは ▶ で即開始。
- `NEXT` / `CLEAR & NEXT` の 2 択をやめ、`OK` と、カード上の WEAK の切り替えに分けた。
- 「REVIEW」と「苦手」の呼び名の揺れをなくし、WEAK に統一。全単語帳の苦手をまとめて復習できる入口を追加。
- コンピレーションからでもカードを直接編集できる（元の単語帳のカードが変わる）。
- 画面ごとに URL のハッシュを持たせ、ブラウザやスマホの「戻る」で戻れるようにした。
- 書き出しはコピーとダウンロードを選べる（AI に貼り付けて追加を頼む用途を想定）。
- 保存できない環境（プライベートブラウズなど）では、その場限りで動かして警告を出す。
