# Visual / interaction guidelines

## 利用者が指定した方向性

- ハッカー／サイバー的で、効率的な UI。
- 基本は黒のダークモード。黒は十分に暗く、アクセントは明確な高コントラスト。
- 基本の表記は英語。細かい操作や説明は日本語。
- 虹系の色をアクセントとして使い、色の順序と役割を考える。
- 操作や状態が分かるシグニファイアを設ける。
- 角丸を使わない。一般的な丸いカード・淡い配色のテンプレート UI に寄せない。
- 別リポジトリの `moai-dash` と近い方向性にする。

## 今回の具体化

以下は指定を受けた実装上の選択。指定そのものと、個々の値・デザインの最終承認は区別する。

### Type

[`moai-dash/src/index.css`](https://github.com/sabmwqes/moai-dash/blob/main/src/index.css) と同じフォント構成を使う。

| 用途 | フォント |
| --- | --- |
| UI・数字・本文 | IBM Plex Mono |
| 見出し | Rajdhani |
| ロゴ | Orbitron |
| 日本語 | 端末の日本語フォントにフォールバック |

フォントは Fontsource 経由でアプリに同梱する。実行時の Google Fonts への通信は不要。
ライセンスを `public/licenses/` に配置する。

### Color

ベースは `#050507`、パネルは `#0c0c10`、主な文字は `#f2f2f5`。

虹の並びは赤 → 橙 → 黄 → 緑 → 水色 → 青 → 紫。
上端の細い帯と、単語帳の色プリセットをこの順にする。新しい単語帳では順番に色を割り当てる。
既存の単語帳のカスタムカラーは書き換えない。

| 色 | 値 | UI での役割 |
| --- | --- | --- |
| 赤 | `#ff526f` | 削除・エラー |
| 橙 | `#ff9d43` | 苦手・再出題 |
| 黄 | `#f5da52` | お気に入り・ヒント・苦手解除 |
| 緑 | `#87f57b` | 主操作・保存済み・答え |
| 水色 | `#45ddf5` | 移動・選択・フォーカス |
| 青 | `#749bff` | 単語帳の色 |
| 紫 | `#c099ff` | コンピレーション・取り込み情報 |

### Layout / signifiers

- 角丸なし。境界線と余白で区切り、影やぼかしに頼らない。
- デスクトップの単語帳一覧は密度のある行形式。スマートフォンでは項目を折り返す。
- 主操作は緑の塗り、補助操作は枠線、削除は赤と `DELETE` の文字で区別する。
- 選択中は色だけでなく、下線・左の線・チェック・`aria-pressed` などでも示す。
- フォーカスは水色の枠、無効な操作は暗い背景とグレーの文字。
- 宣伝的な大きい余白を減らし、検索・件数・学習開始を見つけやすくする。

### Keyboard

| 学習中の操作 | キー |
| --- | --- |
| 答えを表示 | Space |
| 一文字ヒント | H |
| 次へ | Enter |
| もう一度 | R |
| 自動学習の停止・再開 | Space |

入力欄にフォーカスがある場合は学習ショートカットを発動しない。
ボタンにフォーカスした Enter／Space は、そのボタンの通常の操作を優先する。
使えるキーを学習画面に表示する。
