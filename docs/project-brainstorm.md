# プロジェクトのブレインストーミング / 構想殴り書き

## memoaize

- 暗記学習ツール
- React を用いるブラウザアプリケーション
- 🗿 (moai) がトレードマーク

## 基本機能

- 単語帳の作成
- 単語帳の利用
- 単語帳の管理

## 単語帳作成

- 単語帳タイトルと色を指定する
  - 色は基本はプリセット、カスタムカラー（#000000 形式）も指定可能
- 単語帳か、ほかの単語帳のコンピレーションを作成できる
- 単語とその意味をテキスト欄に入力して追加していく
- tsvでのインポートも可能（ファイル / テキスト貼り付け）
  - AI エージェントによる出力をそのまま貼り付けてインポートできるようにしたい（説明を書く）

## 単語帳利用

- 単語帳を選択して学習を開始する
- 意味を隠すか、単語を隠すかを選択して学習を開始する
- 単語（もしくは意味）を表示され、以下の操作ができる
  - 答えを見る
  - 一文字だけ見る
    - 押すたびに一文字ずつ表示される
  - 自動送りモード
    - 秒数指定可
    - 学習開始時に選択できてもいい
- 答えを見た後は、OK / もう一度 を選択して次の単語に

## 単語帳管理
- 単語帳のタイトルと色の変更
- 単語の追加・削除・編集
- 単語帳の削除
- 単語帳のエクスポート（tsv形式）
  - 単体のエクスポート、一括エクスポートも可能
- 単語帳のお気に入り登録
